📘 Panduan Lengkap Sistem

1. Perakitan Hardware (ESP32)

Sistem ini menggunakan ESP32 WROOM dengan sensor sidik jari Multiplexed.

  • ESP32 WROOM DevKit V1
  • Modul Fingerprint R307 (16 Unit)
  • Multiplexer CD4067
  • MicroSD Card Module
  • RTC DS3231
  • Tombol Push Button (Connected via PCF8574)
Komponen Pin ESP32 Keterangan
FP Sensor TX 17 Serial 2 TX
FP Sensor RX 16 Serial 2 RX
MUX S0 - S3 26, 27, 14, 12 Pilih sensor 1-16
SD CS 5 Chip Select SD
SD MOSI 23 SPI Data Out
SD MISO 19 SPI Data In
SD SCK 18 SPI Clock
SDA (I2C) 21 Data RTC & MUX
SCL (I2C) 22 Clock RTC & MUX
PCF8574 (I/O) SDA(21), SCL(22) I2C Address: 0x20 (Tombol Enroll)

2. Cara Menggunakan Aplikasi Web

👮 Admin / Guru
  1. Login menggunakan akun admin@sekolah.sch.id (Pass: admin123).
  2. Buka tab "Data Siswa (FP)".
    • Isi data siswa baru (Nama, Kelas, Jurusan, ID FP).
    • Klik "Simpan Siswa". Data ini akan langsung dikirim ke Firebase.
  3. Buka tab "Manajemen Pengguna".
    • Klik tombol "Pilih Siswa & Generate".
    • Pilih nama siswa yang tadi ditambahkan.
    • Salin Kode 12 Karakter yang muncul.
    • Berikan kode tersebut kepada siswa terkait.
  4. Lihat data absensi real-time di tab "Data Absensi".
🎓 Siswa
  1. Buka aplikasi Web.
  2. Klik "Daftar disini".
  3. Pilih tombol "SISWA".
  4. Masukkan ID Siswa (FP ID) yang tertera di data admin.
    • Jika ID valid, nama dan kelas akan muncul di layar.
    • Jika error "Duplikasi", berarti ID sudah pernah didaftarkan.
    • Jika error "Tidak ditemukan", berarti Admin belum memasukkan data.
  5. Masukkan Email dan Password baru.
  6. Masukkan Kode Pendaftaran yang diberikan Admin (12 Karakter).
  7. Klik "DAFTAR AKUN SISWA".
  8. Login menggunakan akun baru untuk melihat data absensi Anda.
📘 Guru
  1. Login menggunakan akun Admin atau Guru.
  2. Buka "Manajemen Pengguna".
  3. Klik "Generate Guru".
  4. Salin Kode Guru (12 Karakter).
  5. Buka link registrasi siswa, pilih tab "GURU".
  6. Isi Nama, Email, Password, dan Kode.
  7. Daftar berhasil dan akun siap digunakan.

3. Cara Kerja Hardware (ESP32)

MODE ABSEN

Otomatis Scan Fingerprint

System akan otomatis memindai sensor 1 sampai 16 secara bergantian.

Jika jari dikenali, data dikirim ke Firebase dan Log tersimpan di SD Card.

Indikator: Pesan BLE "Nama Masuk" atau "Nama Pulang".

MODE DAFTAR

Pendaftaran Sidik Jari (Enroll)

Tekan TOMBOL (Connected ke PCF8574) selama 3 detik.

1. Sistem akan meminta menempelkan jari 2 kali.
2. Sistem memeriksa duplikasi sidik jari.
3. Jika sukses, data disinkronkan ke Firebase dan ID naik otomatis.

CONNECTIVITY

Sinkronisasi Data

Data dari SD Card akan disinkronkan ke Firebase secara otomatis jika WiFi tersambung.

Waktu RTC disinkronkan dari NTP (Internet) setiap kali ESP32 dinyalakan atau reconnect WiFi.

4. Alur Data Sinkronisasi

1. Web Admin -> Add Siswa -> Firebase (users/{id}) -> ESP32 Download (Update SD)

2. ESP32 -> Scan Jari -> Firebase (absensi/{date}/{id}) + SD Card

3. Web Admin -> Buka Dashboard -> Baca Firebase (Realtime)

🚀 Tips: Pastikan ESP32 dan Web App menggunakan API Key Firebase yang sama agar data sinkron.
